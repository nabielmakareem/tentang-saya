Belajar Variabel JavaScript

Buka DevTools (F12) → tab Console untuk lihat hasil lengkapnya. Hasil juga ditampilkan di bawah tiap bagian.

1. Deklarasi: let, const, var

let umur = 20;      // bisa diubah nilainya
const nama = "Budi"; // TIDAK bisa diubah
var kota = "Jakarta"; // cara lama, hindari

2. Ubah nilai (reassign)

let skor = 10;
skor = 25;        // OK, let boleh diubah
skor = skor + 5;  // 30

3. const tidak bisa diubah

const PI = 3.14;
PI = 5;  // ERROR: Assignment to constant variable

4. Tipe data dasar

let teks   = "halo";     // string
let angka  = 42;         // number
let desimal= 3.14;       // number juga
let benar  = true;       // boolean
let kosong = null;       // null (sengaja kosong)
let belum;               // undefined

5. typeof — cek tipe data

typeof "halo"   // "string"
typeof 42       // "number"

6. Template literal (gabung teks + variabel)

let nama = "Budi";
let umur = 20;
console.log(`Halo ${nama}, umur kamu ${umur} tahun`);

Pakai backtick ` (bukan kutip biasa) dan ${ } untuk sisipkan variabel.

7. Scope (jangkauan variabel)

let luar = "bisa diakses di mana saja";

if (true) {
    let dalam = "cuma hidup di dalam blok ini";
    console.log(luar);  // OK
    console.log(dalam); // OK
}

console.log(luar);   // OK
console.log(dalam);  // ERROR: not defined

8. Aturan penamaan

let namaLengkap = "Budi";  // camelCase (disarankan)
let _private    = 1;        // boleh diawali _
let $harga      = 100;      // boleh diawali $

// TIDAK boleh:
// let 2umur = 20;   (tidak boleh diawali angka)
// let nama lengkap = ""; (tidak boleh ada spasi)
// let class = "x";  (kata kunci bahasa)

9. Array — daftar nilai berurutan

// bikin array pakai kurung siku [ ]
const buah = ["apel", "jeruk", "mangga"];

// index dimulai dari 0, bukan 1
buah[0]   // "apel"
buah[2]   // "mangga"
buah.length // 3

// tambah / hapus di AKHIR
buah.push("pisang");  // tambah di belakang
buah.pop();           // buang yang paling belakang

// tambah / hapus di DEPAN
buah.unshift("anggur"); // tambah di depan
buah.shift();           // buang yang paling depan

// cari
buah.includes("jeruk"); // true / false
buah.indexOf("jeruk");  // posisinya, -1 kalau tidak ada

// ubah jadi teks
buah.join(", ");        // "apel, jeruk, mangga"

10. Object — data berpasangan nama: nilai

// bikin object pakai kurung kurawal { }
const user = {
    nama: "Budi",      // key: value
    umur: 20,
    kota: "Jakarta"
};

// akses nilai
user.nama        // "Budi"  (dot, cara utama)
user["umur"]     // 20      (bracket, untuk key dinamis)

// ubah / tambah properti
user.umur = 21;
user.email = "budi@mail.com";

// hapus properti
delete user.kota;

11. Array of Object — kombinasi keduanya

const pengguna = [
    { nama: "Budi", umur: 20 },
    { nama: "Ani",  umur: 22 },
    { nama: "Cici", umur: 19 }
];

// akses: index dulu, baru key
pengguna[0].nama   // "Budi"

// ambil semua nama jadi array baru
pengguna.map(p => p.nama)   // ["Budi", "Ani", "Cici"]

// filter: ambil yang umurnya 20 ke atas
pengguna.filter(p => p.umur >= 20)

Ini bentuk data yang paling sering kamu temui di dunia nyata — hasil dari API hampir selalu array berisi object.

12. Kapan pakai const vs let

Pakai const sebagai default. Ganti ke let hanya kalau nilainya memang perlu berubah. Ini bikin kode lebih aman — kalau tidak sengaja menimpa nilai, langsung error ketimbang bug diam-diam.

var: cara lama sebelum ES6 (2015). Punya masalah scope & hoisting yang aneh. Jangan dipakai di kode baru, tapi perlu tahu karena masih ada di kode lama.
