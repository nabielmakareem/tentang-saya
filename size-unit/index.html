Size Unit CSS

Satuan ukuran di CSS dibagi 2: absolute (tetap, tidak peduli apa pun) dan relative (ikut patokan di sekitarnya).

1. px (absolute)

Satuannya tetap. 100px ya 100 pixel, tidak terpengaruh font-size atau ukuran layar.

100px × 100px

2. rem (relative ke <html>)

1rem = font-size root (html). Default browser 16px, jadi 2rem = 32px. Ubah font-size html, semua rem ikut berubah.

2rem × 2rem (font-size normal)
2rem × 2rem (parent font-size 24px)

Kotak hijau tetap ukurannya walau font-size parent diubah → karena rem cuma peduli root, bukan parent.

3. em (relative ke parent / elemen sendiri)

em itu bertingkat — ikut font-size elemen itu sendiri (atau parent-nya kalau dipakai di font-size). Ini yang sering bikin bingung.

2em × 2em (parent 16px) → 32px
2em × 2em (parent 24px) → 48px

Bandingkan dengan rem di atas: em ikut membesar karena patokannya parent.

4. % (relative ke parent)

width: 50% = setengah lebar parent. Perhatikan: padding: 10% dihitung dari lebar parent, bukan tinggi — walau padding-nya vertikal.

width: 50%

5. vw / vh / vmin / vmax (relative ke layar)

Patokannya ukuran viewport (jendela browser). 1vw = 1% lebar layar, 1vh = 1% tinggi layar. Coba resize jendela.

10vw × 10vh

6. Rangkuman

Unit Patokan Kapan dipakai
pxpixel, tetapborder, ukuran presisi yang tidak boleh berubah
remfont-size <html>font-size, spacing, ukuran global — paling disarankan
emfont-size parent/elemenpadding tombol yang mau ikut ukuran teksnya
%ukuran parentlebar kolom, layout fleksibel
vw / vhviewport (layar)section full-screen, hero banner
vmin / vmaxsisi terkecil/terbesar layarelemen yang aman di layar portrait & landscape

Tips: font-size pakai rem (aksesibilitas — ikut setting zoom user), spacing pakai rem, border pakai px, tinggi full-screen pakai vh atau 100dvh (mobile-friendly).
